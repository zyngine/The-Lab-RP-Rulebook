# The Lab RP — Rulebook

Source for the public city rules, built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) and published via GitHub Pages.

**Edit a rule:** change the matching file in `docs/`, commit to `main`, and the site rebuilds automatically.
**Add a page:** create a new `docs/whatever.md` and add it to the `nav:` list in `mkdocs.yml`.

Preview locally with `pip install mkdocs-material` then `mkdocs serve`.
